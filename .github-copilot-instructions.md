# Auto-Deploy System Context for AI Assistants

## System Overview
This project has an **automatic Supabase Edge Functions deployment system**.

## Key Facts
- **Any save to `/supabase/functions/*/index.ts` automatically deploys**
- Watcher starts automatically with `npm run dev`
- No manual `supabase functions deploy` commands needed
- 2-second debounce, SHA256 hash-based change detection

## Important Commands
- `npm run init:watcher` - First-time setup
- `npm run watcher:status` - Check if running
- `npm run watcher:logs` - View deployment logs
- `npm run watcher:restart` - Restart if needed

## Files to Know
- `deploy-functions.mjs` - Core watcher logic
- `ensure-watcher.mjs` - Auto-start helper
- `watcher.pid` - Tracks running process
- `logs/watcher.log` - Watcher logs
- `logs/deployments.log` - Deployment history

## When Helping Users
1. Remind them saves trigger auto-deploy
2. Check watcher status if deployments aren't working
3. Suggest `npm run watcher:logs` to debug
4. Never suggest manual `supabase functions deploy`
